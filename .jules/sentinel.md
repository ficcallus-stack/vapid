## 2024-09-01 - Insecure Token Generation\n**Vulnerability:** Weak random number generation (`Math.random()`) is used for generating security-sensitive tokens, OTPs, referral codes, and passwords across the application.\n**Learning:** Relying on `Math.random()` for cryptographic purposes is insecure because it is predictable, making the application vulnerable to token guessing and unauthorized access. \n**Prevention:** Always use a Cryptographically Secure Pseudo-Random Number Generator (CSPRNG), such as Node.js's `crypto.randomBytes()` or `crypto.getRandomValues()`, for security-related random value generation.
