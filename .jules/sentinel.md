## 2026-08-29 - [Defense in Depth] Replaced SQL Template Literal with ORM Function
**Vulnerability:** Found a potential SQL injection vector in `src/app/jobs/page.tsx` where user input `query` was concatenated within a Drizzle `sql` template tag (e.g., `sql`LOWER(${jobs.title}) LIKE LOWER(${'%' + query + '%'})``). Although Drizzle's `sql` tag parameterizes inputs and is safe, it's considered a security risk and poor practice to use raw SQL constructs when native ORM functions are available.
**Learning:** The codebase previously contained a few instances where `sql` template tags were used for simple queries instead of built-in Drizzle functions. This practice could lead to actual SQL injection vulnerabilities if future developers misunderstand the `sql` tag and concatenate raw strings instead of using parameterization.
**Prevention:** Replaced the `sql` template literal with Drizzle's native `ilike` function to ensure defense-in-depth, improve code readability, and prevent future accidental misuse.
