## 2025-05-18 - [Fix Insecure Pseudo-Random Number Generators]\n**Vulnerability:** The codebase was utilizing `Math.random()` to generate sensitive One-Time Passwords (OTPs), reference tokens, and referral codes across `src/app/api/auth/send-otp/route.ts`, `src/app/dashboard/nanny/verification/actions.ts`, and `src/db/schema.ts`.\n**Learning:** `Math.random()` is not cryptographically secure and the resulting values can be predicted, compromising the security of the application and users accounts.\n**Prevention:** Node.js native `crypto` module (`randomInt`, `randomUUID`, `randomBytes`) should always be used to generate secure and unpredictable pseudo-random numbers.
